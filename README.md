## Опис

Сервіс надає CRUD-операції для ресурсу Order:
- створення, отримання, оновлення та видалення замовлень;
- зберігання даних у PostgreSQL;
- автоматичний розрахунок totalCost на основі цін продуктів;
- health-check контролер для перевірки працездатності.
