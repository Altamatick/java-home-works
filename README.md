Калькулятор (HTML/CSS/JS)

Опис

Простий інтерактивний калькулятор, який підтримує додавання, віднімання, множення, ділення, дужки, backspace та очистку. Вирази парсяться без використання eval(), реалізовано токенайзер та алгоритм "shunting-yard".

Запуск

Відкрийте `index.html` у браузері (подвійний клік або через Live Server в редакторі).

Клавіатура

- 0-9 і . для цифр
- + - * / для операцій
- Enter для "="
- Backspace для видалення останнього символу
- Esc для очищення

Обмеження та обробка помилок

- Ділення на нуль показує повідомлення про помилку
- Невірні вирази показують "Невірний вираз"
